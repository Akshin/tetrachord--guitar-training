# Tetrachord

Тренировка тетрахордов: две схемы и связующий тон складываются в лад. Играешь его под метроном, пока карточка сама не сменится.

## Как тренироваться

1. Открой **Игру**. Слева **Сейчас**, справа следующий лад и секунды до смены.
2. Выбери тональность. Метроном лучше оставить включённым. Мелодия проигрывает восемь нот лада за такт — по ней слышно, что показывать руками.
3. Нажми Play. Играй левую карточку от тоники: зелёный — тон (два лада / два полутона), жёлтый — полутон (соседний лад), серый ТС — тон между схемами. Над карточкой — пара схем (S1 + S3).
4. Когда правая карточка переезжает налево — это уже **Сейчас**. Не останавливайся.
5. Смену можно разредить: раз в такт или раз в несколько тактов. Таймер справа считает секунды до этой смены (темп, размер, сколько тактов).
6. Если гриф не читается с ходу — включи табы: гитара (первая позиция, лады 1–4) или пианино.

Схему играют и вверх, и вниз: нисходящий ход — это та же схема задом наперёд.

## Что на карточке

Тетрахорд — четыре ступени в пределах чистой кварты. В игре их три вида:

1. **S1** · тон — тон — полутон
2. **S2** · тон — полутон — тон
3. **S3** · полутон — тон — тон

Лад = нижняя схема + **ТС** (тон связующий) + верхняя схема. Восемь нот, октава.

| Интервал      | Цвет    |
| ------------- | ------- |
| Тон           | зелёный |
| Полутон       | жёлтый  |
| Тон связующий | серый   |

Если пара схем совпадает с диатоническим ладом, под карточкой появляется имя:

- Ионийский · натуральный мажор — ТТП + ТС + ТТП
- Дорийский — ТПТ + ТС + ТПТ
- Фригийский — ПТТ + ТС + ПТТ
- Миксолидийский — ТТП + ТС + ТПТ
- Эолийский · натуральный минор — ТПТ + ТС + ПТТ

Остальные комбинации безымянные — их тоже играют. Лидийский и локрийский в случайной выдаче не появляются: им нужна схема тон–тон–тон.

## Экран игры

- **Ритм** — темп, размер, метроном (клики можно выключить, пульс схем останется).
- **Упражнение** — как часто менять лад; табы Нет / Гитара / Пианино.
- **Звук** — общая тональность, мелодия, бэк-трек.
- Play внизу. Настройки прячутся крестиком, Play остаётся.

## Запуск

